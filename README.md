Config For Tools


This is the repository where I host files for the config of some aplications that I have installed

Those are, respectivly, :

Kitty Terminal (the corresponding files are current-theme.conf and kitty.conf, and to work they need to be in /home/$USER/.config/kitty )

Starship Prompt (The file, to work, need to be in /home/$USER/.config)

nvim (I use lazyvim for look  and the "snap --classic" for the package)(Iĺl also provide my lazyvim config, so you don't have to :)

Rofi app launcher (The corresponding files are config.rasi and spotlight-dark.rasi)(To work they need to be in /home/$USER/.config/rofi)

i3wm (the corresponding file is "config", and to work it has to be in /home/$USER/.config/i3/ ) 

polybar files (they will work if in /home/$USER/.config/polybar )

and more to come :) ...

for this "setup" to work, you need to install:

kitty 

starship, and add to your .bashrc this line: ' eval "$(starship init bash)" ' (if you use anothe shell go to https://starship.rs/ to find the correct line for each shell)

nvim, at the time of writting only the snap --classic version works with lazyvim (on my linux system) 

rofi 

i3wm

feh

wpctl

brightnessctl

numlockx

volumeicon
